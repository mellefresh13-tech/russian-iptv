# Русский IPTV

Сборный плейлист открытых IPTV-потоков без авторизации. Включает русскоязычные каналы России, Беларуси и Украины, а также популярные европейские новостные каналы. Дубли удаляются по `tvg-id` или нормализованному названию.

## Использование

- Плейлист: [`playlist.m3u`](./playlist.m3u)
- EPG: `https://xmltv.live/epg/ru.xml.gz` (уже прописан в `#EXT-X-TVG-URL`)
- Отчёт последней сборки: [`build-report.txt`](./build-report.txt)

Для приложения можно использовать URL raw-файла:
`https://raw.githubusercontent.com/mellefresh13-tech/russian-iptv/main/playlist.m3u`

## Автообновление

GitHub Actions запускает сборку каждые 12 часов (00:00 и 12:00 UTC), а также вручную. Расписание настраивается одной видимой строкой `cron` в `.github/workflows/update.yml` (формат cron); по умолчанию `0 */12 * * *`.

Перед публикацией обновления источники загружаются заново, дубликаты удаляются, а URL потоков проверяются коротким HTTP-запросом. Нестабильные, геоблокированные и требующие авторизации обычные потоки исключаются. В текущей проверке осталось 1 658 live-кандидатов, из них 1 635 ответили успешно; 1 158 записей `18+` отсеяны как VOD/не-live.

В плейлист допускаются только признаки эфирного потока (`m3u8`, `TS`, HLS, RTMP, live/stream/channel/manifest). Прямые видеофайлы, VOD, каталоги и ролики исключаются для всех категорий. Дедупликация выполняется одновременно по нормализованному `tvg-id` и названию; разрешение и часовые пояса из названий удаляются.

## Категории

Категории берутся из метаданных источника и нормализуются в русские названия. `18+` всегда находится последней. Для этой категории не требуется EPG или логотип; ссылки сохранены отдельным блоком и помечены в отчёте как непроверенные, если провайдер не отвечает.

## Источники и ограничения

- 19 каталогов потоков: iptv-org, Free-TV/IPTV, streamline-iptv, dearbulut, ngrch, FoxStudio24 и отдельные публичные adult-каталоги.
- RedTraffic добавлен отдельным источником; берутся только ссылки `redtraffic` с признаками live-потока, `livecams` исключаются.
- 6 независимых источников для `18+`: yxcqr, zeckelektronik, syukriadi и три публичных GitHub Gist.
- [xmltv.live](https://xmltv.live/epg) — публичный XMLTV EPG; покрытие зависит от канала.

Потоки принадлежат их правообладателям и могут быть недоступны в отдельных странах. Репозиторий не размещает видеоданные, а только ссылки на опубликованные источники.
